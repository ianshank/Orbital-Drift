### Added — governance hardening (2026-08-21)
- `src/orbital_drift/guard.py`: PreToolUse command analyzer, replacing the
  `sed`+ERE tokenizer that shipped in the initial import. Uses `shlex`,
  recursively lifts command substitutions into their own segments, strips
  wrapper commands and env assignments, re-analyzes `bash -c` payloads as
  code, and resolves `git push` destinations without ever assuming a default
  remote.
- `src/orbital_drift/covcheck.py`: per-file coverage floor (90%,
  `PER_FILE_FLOOR` in `covcheck.py`), run after the global floor so a
  fully-untested new module cannot hide behind a healthy aggregate. (This
  batch originally proposed raising the global floor 90 → 95; that proposal
  was superseded at the RB-006 reconciliation — the operator-ratified GLOBAL
  floor is **85**, `COVERAGE_MIN_PERCENT` in `ci/versions.env`, enforced by
  `stage_coverage`, with the per-file 90 floor retained as an additive check
  wired into `stage_coverage`'s success path. Measured at commit `7c4d0d9`.)
- `scripts/_lib.sh`: shared venv-Python discovery and allowlist-path
  resolution, replacing three previously-divergent copies in
  `pretooluse_guard.sh`, `pre_push_scan.sh`, and `session_start_check.sh`.
- `scripts/guard_probe.sh`: standalone guard probe, so `make guard-probe`
  works without GNU make (not installed on the authoring machine).
- `ci/checks.sh` `governance` stage: `tests/governance/` now runs under its
  own stage name instead of only inside the `cov` stage's bare `pytest`.
- `.claude/skills/run-the-gate/`, `.claude/skills/log-decision/`: skills
  extracted from repeated actions this session (correct gate invocation on
  this machine; the decision-log/skill-freshness two-file coupling).
- Regression corpus (`tests/governance/test_pretooluse_guard.py`,
  `tests/unit/test_guard.py`): ten measured guard bypasses pinned as tests so
  they can never silently return.

### Fixed — governance hardening (2026-08-21)
- **PreToolUse guard fail-open (Blocker).** Four command shapes were measured
  as ALLOWED by the original `sed`+ERE guard: a co-located `git` token routing
  a dangerous segment into the (allow-listed) push branch
  (`kubectl delete ns $(git rev-parse --abbrev-ref HEAD)`,
  `helm upgrade rel ./chart --set sha=$(git rev-parse HEAD)`,
  `terraform apply -var git_sha=$(git rev-parse HEAD)`), and a flag value
  containing `/` hiding the push verb from the pattern entirely
  (`git -C /somewhere push evil main`). Fixed by moving classification into
  `orbital_drift.guard` (commit `4ba5774`).
- Zero-skip capability-guard allowance was a substring match, so a parked skip
  could be excused by mentioning the token mid-sentence; anchored to a prefix.
- `stage_cov` lacked the Docker/git preflight `stage_unit` has, so a
  Docker-less box let the gitleaks positive controls skip and reported green
  coverage having never run them.
- Coverage-drift comparison used `read_text()` (universal-newline
  translation), so a CRLF checkout compared equal to LF output despite
  differing bytes; the "byte-match" claim in `projections.py` was not
  literally true until this fix.
- `roadmap_data.owner_stories_carry_no_points()` checked only `points == 0`,
  not the "owner" label — a labelled-owner story carrying points passed a
  guard whose name promised otherwise.
- `Makefile`: every `$(ROOT)` interpolation is now quoted (a repository path
  containing a space could otherwise split an argument to
  `find ... -exec rm -rf`).

  `docs/decisions/versions.md`), and the first project-authored image
  (the STAC ingest / training entrypoints) does not exist before T016/T026.
  A `Dockerfile` and `.dockerignore` land with that image, not before.
